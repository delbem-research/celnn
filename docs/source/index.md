# CELNN Technical Knowledge System

This documentation layer connects Cellular Neural Network theory, numerical
reasoning, the public `celnn` API, implementation ownership, and executable
evidence. It is intentionally independent from the installable library.

The current release contains one vertical proof slice plus a generated public
reference. Existing guides remain available while they are migrated
incrementally.
